Contrato compartilhado

Pessoas e agentes de IA podem adaptar o tema mantendo os tokens, as classes .ui-*, os estados .is-* e os atributos data-ui-*.

1. Abra o projeto

O servidor nativo do Python é suficiente para a demonstração.

python3 -m http.server 4173

# abra:
http://127.0.0.1:4173

2. Carregue o núcleo

Declare somente as bibliotecas usadas naquela página.

<script src="assets/js/vendor.js"
  data-vendors="poppins,lucide"></script>
<link rel="stylesheet" href="assets/css/theme.css">
<script src="assets/js/theme.js" defer></script>

Contrato de nomes

.ui-* identifica componentes, .is-* representa estados e data-ui-* conecta comportamentos. Não use texto visível como seletor JavaScript.

.ui-button.is-danger        /* componente + estado */
[data-ui-menu]              /* comportamento */
[data-ui-reveal]            /* entrada progressiva */
[data-ui-loading-trigger]   /* loading demonstrativo */
[data-ui-data-table]        /* tabela funcional */
[data-ui-table-sort]        /* coluna ordenável */
[data-ui-table-export]      /* PDF, Excel ou impressão */
