# Logos de autenticação

Assets de identificação dos provedores, consultados em 10/09/2026.
Não representam parceria nem autenticação implementada.

- microsoft.svg: SVG original do [Microsoft Learn](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg).
  [Diretrizes de login](https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps).
- google.svg: caminhos SVG preservados do configurador HTML oficial das
  [diretrizes Google Identity](https://developers.google.com/identity/branding-guidelines).
  O botão usa a variante clara; fonte Arial conforme o fallback do configurador,
  logo em 20px, borda e cores de marca. Não recolorir o G.
- cyberark.ico: símbolo original de [CyberArk](https://lp.cyberark.com/rs/316-CZP-275/images/favicon-CyberArk.ico),
  referenciado pela [página oficial](https://lp.cyberark.com/Stay-in-touch.html).
  ICO com 16px e 32px, exibido proporcionalmente em 20px, sem modificações.

Marcas pertencem aos respectivos titulares. Consulte as condições do provedor
antes de redistribuir sua aplicação. Os assets não herdam uma licença do tema.
